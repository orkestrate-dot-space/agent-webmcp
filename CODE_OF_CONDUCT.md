# Code of Conduct

Be kind and direct. Criticize code and ideas, never people. No harassment,
hate speech, or unwelcome personal attention, in issues, PRs, or any project
space. Submitting a site for listing is not an endorsement of its content; the
index records what pages register, nothing more.

Violations: maintainers may warn, then remove the contributor from project
spaces. Reports go to support@orkestrate.space and are kept confidential.
